    • Strict type-safety across all REST endpoints

    • Real-time status broadcasts to UI clients

PostgreSQL

Relational Data Source

  • Operational Source of Truth
    • Centralized patient, stock, and hardware records
  • Transaction Rollbacks
    • Database reverts if hardware dispatch fails
  • Zod Schema Validation
    • Strict request payload sanitization

The Bridge: Connecting AI to Database

Unstructured to Structured

  • FastAPI OCR Pipeline
    • Extracts raw handwriting from prescription images
  • JSON Normalization
    • GLM-OCR / Llama models structure text into usable API payloads
  • DB Match Guardrails
    • AI output is strictly queried against live PostgreSQL inventory
  • Expiry Checkout Block
    • System automatically rejects AI matches linked to expired bins
